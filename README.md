ForTEA 🧩

O ForTEA é um projeto desenvolvido como Trabalho de Conclusão de Curso (TCC), com o objetivo de oferecer um espaço de informação e apoio para pessoas autistas e seus familiares.

A plataforma reúne conteúdos sobre o Transtorno do Espectro Autista (TEA), direitos, inclusão escolar, profissionais, orientações para famílias e materiais de apoio.

Além da parte informativa, o sistema possui uma área de Minha Trajetória, onde o usuário pode registrar informações importantes, acompanhar checklists e organizar acontecimentos relacionados à sua jornada.

Funcionalidades

Informações sobre o TEA;

Guia para famílias;

Informações sobre direitos;

Conteúdos sobre inclusão escolar;

Área de profissionais e rede de apoio;

Materiais e conteúdos de apoio;

Sistema de registros e checklists;

Área de acompanhamento da trajetória do usuário;

Recursos de acessibilidade.

Como executar

O projeto pode ser executado utilizando um servidor local, como o XAMPP.

Coloque os arquivos do projeto na pasta htdocs;

Configure o banco de dados MySQL;

Ajuste as informações de conexão no arquivo conexao.php;

Inicie o Apache e o MySQL pelo XAMPP;

Acesse o projeto pelo navegador.

Público-alvo

O ForTEA foi pensado principalmente para:

Pessoas autistas;

Familiares e responsáveis;

Educadores;

Pessoas que fazem parte da rede de apoio.

Observação

O conteúdo disponibilizado pelo ForTEA possui finalidade informativa e não substitui avaliação ou acompanhamento de profissionais especializados.
